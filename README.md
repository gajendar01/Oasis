Project Overview :-

Oasis is a centralized web platform that enables students, organizers, club coordinators, and college administrators to manage the complete lifecycle of college events through a single system.

The platform simplifies event creation, registrations, attendance tracking, participant management, and certificate distribution while replacing fragmented tools such as WhatsApp groups, Google Forms, Excel sheets, and emails.

Technology Stack:-

Frontend:

- React.js
- Vite
- Tailwind CSS

Backend:

- Node.js
- Express.js

Database:

- MongoDB

Authentication:

- JWT (JSON Web Token)

Setup & Run Instructions:-

Step 1: Clone the Repository

git clone https://github.com/gajendar01/Oasis.git

Step 2: Navigate to the Project Directory

cd Oasis

Step 3: Navigate to the Frontend Directory

cd frontend

Step 4: Install Dependencies

npm install

Step 5: Run the Development Server

npm run dev

Step 6: Open in Browser

Open the local URL displayed in the terminal
